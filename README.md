# lilynhuynh.github.io

Personal portfolio of Lily Huynh, served by GitHub Pages at <https://lilynhuynh.github.io>.

A single static page, no build step:

- `index.html` - the whole site (markup + styles)
- `assets/` - profile photo and logos

To preview locally, open `index.html` in a browser or run `python3 -m http.server` in this folder.
